# Contributing

Focused bug reports, compatibility findings, tests, and documentation improvements are welcome.

## Report a problem

Search existing issues, then include your Warcraft III client version, graphics mode, map type, scenario configuration, exact steps, expected behavior, actual result, and any error text or screenshot. Test with the latest release and a clean copy of the included demo when practical. Remove account details and private paths from logs and images.

## Pull requests

Keep each change focused. Explain the problem it solves and how you tested it. Preserve cleanup isolation and logical A/B scoring. Run `python Tests/run_standalone.py` with Lupa installed, and test gameplay changes in Warcraft III. Do not bundle unrelated maps or external tools.
