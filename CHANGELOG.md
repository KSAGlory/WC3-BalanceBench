# Changelog

## v1.0.0 — 2026-09-28

First public release of WC3 Balance Bench.

- Repeated ordinary-unit matchups with configurable teams, rounds, timeout, and arena.
- Alternating sides and test player slots with logical A/B scoring.
- In-game commands for start, stop, and repeatable reports.
- Cleanup of owned units and handles on completion, abort, and errors.
- Playable demo plus labeled stock and custom Footman comparison maps.
- World Editor source metadata and a portable-path map builder.
- Fake-native lifecycle tests and a record of local Warcraft III checks.
