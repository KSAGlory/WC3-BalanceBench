# Support

For installation help, usage questions, or reproducible bugs, use [GitHub Issues](https://github.com/KSAGlory/WC3-BalanceBench/issues). Search existing issues first.

Include your Warcraft III version, graphics mode, map path and type, configuration, and steps to reproduce. State what you expected and what happened. Remove private information from screenshots and logs.

For a potential security issue, use [private vulnerability reporting](SECURITY.md).
