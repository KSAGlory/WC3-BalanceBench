# Security policy

Security fixes target the latest official release.

Report a potential vulnerability through [GitHub private vulnerability reporting](https://github.com/KSAGlory/WC3-BalanceBench/security/advisories/new). Include the affected version, minimal reproduction steps, impact, and a suggested fix if you have one. Do not put passwords, tokens, or private map data in a report.

For ordinary bugs and installation questions, use [GitHub Issues](https://github.com/KSAGlory/WC3-BalanceBench/issues).
